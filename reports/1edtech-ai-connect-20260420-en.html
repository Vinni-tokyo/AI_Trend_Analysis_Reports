1EdTech AI-Connect 1.0:
A New Specification for Standardizing Contextual Understanding in Educational AI

Inside the MCP-Based Educational Context Sharing Framework
Report Date: April 20, 2026 | Standard Report (5-8 pages)

Top 5 Trends

1. AI-Connect 1.0: A New Paradigm for Educational AI Standardization

Current Status: On October 22, 2025, the 1EdTech Consortium announced a K-20 cross-sector collaboration to develop "AI-Connect" (formally the AI Data Context Standard 1.0), a new framework designed to support the responsible use of AI in education. Built on Anthropic's Model Context Protocol (MCP), it is the first open framework specifically aimed at providing trusted educational context to AI models.

Core Capabilities

• Standardized context sharing: Securely conveys learner, curriculum, and outcome information to AI
• MCP-based design: Uses an industry-standard protocol for flexible extensibility
• Privacy boundaries: Explicitly defines what data can and cannot be shared

Development Structure

• K-20 collaboration: Spans primary, secondary, higher ed, and workforce learning
• 1EdTech Labs: Technical working groups validate use cases and set best practices
• Early engagement: First public webinar held on October 23, 2025

🔗 Related Links: 1EdTech Official Announcement | Model Context Protocol | 1EdTech Consortium

Outlook: The formal specification is expected to publish within 2026, with details rolled out across the London Summit (January 20), the Learning Impact Conference in San Francisco (June 1-3), and Learning Impact Europe in Thessaloniki (September 15-17).

2. Integration Architecture with Existing 1EdTech Standards

Current Status: AI-Connect is designed to interoperate deeply with existing open standards so institutions can fully leverage their current data assets. CASE (Competencies and Academic Standards Exchange), OneRoster (roster data exchange), Edu-API (administrative data integration), and Caliper Analytics (learning analytics) act as the primary sources of context delivered to AI.

Existing Standards Leveraged

• CASE®: Aligns with all 50 US state frameworks, NGSS, and CCSS
• OneRoster® 1.2: Secure exchange of roster, course, and grade data
• Edu-API™: Integration with Student Information Systems (SIS)

Additional Data Linkages

• Caliper Analytics® 1.2: Standardized learning behavior logs
• CLR 2.0: Comprehensive Learner Record (verifiable digital form)
• Open Badges 3.0: W3C Verifiable Credentials compliant

🔗 Related Links: CASE Standard | OneRoster | Edu-API | Product Roadmap

Outlook: Rather than "building AI from scratch," AI-Connect takes the approach of "embedding AI safely into existing trust infrastructure." Institutions can transition to AI-ready systems without abandoning prior technology investments.

3. Three Pillars: Privacy, Security, and Governance

Current Status: At the heart of AI-Connect is a mechanism allowing institutions to control what AI is allowed to know—and what must remain private. According to 1EdTech, 2026 marks the transition of educational AI from an "experimental" phase to a "governance" phase, and this standard sits at the center of that shift (Source: 1EdTech "Three Trends We're Watching in 2026").

Integrated Protection Frameworks

• TrustEd Apps AI Data Rubric: Privacy evaluation
• Security Framework v1.1: Information security practices
• AI Preparedness Checklist: Pre-adoption readiness check

Controllable Elements

• Data boundaries: Field-level control over shared/unshared data
• Consent management: Explicit opt-in / opt-out flows
• Audit readiness: Transparent logging of context AI consumed

🔗 Related Links: TrustEd Apps AI Rubric | AI Preparedness Checklist

Outlook: An expanded Generative AI Rubric is planned for release in early 2026, adding evaluation criteria for data quality, validity, and ownership on top of privacy. This will provide implementation-level evaluation benchmarks for AI-Connect deployments.

4. The Rise of Education-Specific MCP Server Ecosystems

Current Status: MCP was released by Anthropic in November 2024 and graduated to a multi-company open standard under the Linux Foundation in March 2026. In education, MCP servers that integrate with Canvas LMS, Moodle, Google Classroom, and the OneRoster API have emerged in rapid succession. AI-Connect's position is to add a "shared, education-specific context layer" on top of this ecosystem.

Example Education MCP Servers

• OneRoster MCP: TypeScript SDK-based roster integration
• Canvas & Moodle connectors: LMS workflow automation
• O'Reilly MCP: Injects learning content directly into workflows

Where AI-Connect Adds Value

• Semantic context: Conveys educational meaning, not just API payloads
• Standards-aligned: Unifies semantic frameworks like CASE/CLR
• Governance: Institution-level control over what AI may access

🔗 Related Links: MCP Official | MCP Servers GitHub

Outlook: If AI-Connect is broadly adopted, EdTech vendors can advertise "1EdTech-compliant" MCP server implementations, while institutions gain interoperability guarantees as they deploy AI.

5. Expanded Generative AI Rubric and Evaluation Framework

Current Status: 1EdTech plans to publish an expanded Generative AI Data Rubric in early 2026. Beyond the current (privacy-only) section, it will add evaluation criteria for data quality, validity, ownership, and bias control, serving as a common self-assessment yardstick for vendors and institutions implementing AI-Connect 1.0 (Source: 1EdTech AI Rubric official page).

Current Rubric Axes (Privacy)

• Disclosure policies: Stating where AI is used
• Opt-in/opt-out: Ensuring user choice
• Data ownership: Attribution of learner data

Planned Expansion Axes

• Data quality: Reliability of training data
• Bias control: Fairness safeguards
• Verifiability: Validity assessment of AI outputs

🔗 Related Links: Generative AI Data Rubric | Rubric PDF

Outlook: Expanding the rubric is expected to standardize EdTech procurement workflows, giving school districts and universities a common language for evaluating AI products.

Major Market Shifts (Five Trends)

  • General → Domain-Specific: Differentiation from general MCP into domain-specific context standards (education, healthcare, finance)
  • Experimentation → Governance: Focus moving from "what AI can do" to "how we control it"
  • Single Standard → Integrated Ecosystem: Cross-utilization of CASE, OneRoster, and Open Badges becomes a baseline
  • Vendor-Led → Consortium-Led: Emphasis on collective K-20 consensus-building
  • Data Protection → Context Quality: Beyond privacy, data quality and bias evaluation emerge as new focal points

Application Ideas

The following are key application approaches observed in the market.

1. Pilot Deployment Assessment - Validate AI assistant integration via an AI-Connect bridge against an existing OneRoster-compliant LMS

2. Leveraging Existing CASE Assets - Use already-managed CASE competencies as AI context to enable personalized learning experiences

3. Establishing Governance Baselines - Reference the expanded AI Rubric to define internal AI data boundaries and opt-in policies

Executive Summary

Key Findings

  • A Standards Milestone: AI-Connect 1.0 is the first MCP-based industry standard for education, marking a step-change in AI-education interoperability
  • Asset Reuse: Existing 1EdTech standards such as CASE, OneRoster, Edu-API, and Caliper can be repurposed as context sources
  • Governance Imperative: 2026 is the year educational AI moves from "experimental" to "governed," with AI-Connect at the center
  • Phased Disclosure: Specification details will roll out progressively across the London Summit, Learning Impact Conference, and Learning Impact Europe in 2026
  • Self-Assessment Tools: The expanded Generative AI Rubric (early 2026) will serve as a common evaluation measure for vendors and institutions

Selection Guide

Organizations already using many 1EdTech standards → Consider an AI-Connect 1.0 pilot
Rationale: Existing CASE/OneRoster assets can be reused directly as AI context, producing high investment efficiency.
Organizations prioritizing AI governance → Pair the expanded AI Rubric with AI-Connect
Rationale: Offers a common yardstick covering privacy plus data quality and bias evaluation.
Organizations building proprietary AI → Use general-purpose MCP + AI-Connect compliance profile
Rationale: Combines MCP's flexibility with education-sector interoperability.

Overall Assessment: Positive. AI-Connect preserves prior investment while raising the bar for trustworthy, interoperable educational AI. The pace at which reference implementations emerge after the formal specification release will be the key driver of adoption.

Key Terminology

AI-Connect 1.0 - The MCP-based educational AI context sharing standard under development at 1EdTech. Formally named the AI Data Context Standard.
MCP (Model Context Protocol) - An open standard released by Anthropic in 2024 for connecting AI applications to external data and tools. Governed by the Linux Foundation starting in 2026.
CASE® (Competencies and Academic Standards Exchange) - A 1EdTech standard for digitally exchanging academic competencies and learning standards.
OneRoster® - A 1EdTech standard for exchanging roster, course, and grade information between school systems. Current version 1.2.
Edu-API™ - A 1EdTech standard for integrating Student Information Systems (SIS) with educational applications.
K-20 - Shorthand for the full education continuum, from kindergarten through graduate education (year 20).
TrustEd Apps Rubric - A 1EdTech self-assessment framework for evaluating the trustworthiness of EdTech products (privacy, security, accessibility, etc.).
