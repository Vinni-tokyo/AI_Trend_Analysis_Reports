1EdTech CASE & CLR
글로벌 활용 사례와 Best Practice 분석

역량 및 학업 표준 교환(CASE)과 종합 학습자 기록(CLR)의 글로벌 도입 현황
레포트 작성일: 2026년 3월 30일 | 표준 레포트 (5-8페이지)

주요 트렌드 Top 5

1. CASE 1.1 표준과 CASE Global Ecosystem: 전 세계 학습 표준의 디지털 통합

현황: 2025년 4월 CASE 1.1 표준이 공식 출시되었으며, 학습 표준, 학업 역량, 스킬 프레임워크를 기계 판독 가능한 디지털 형식으로 게시·교환하는 표준 방식을 확립했습니다. 2026년 Digital Credentials Summit에서는 'CASE Network 2'라는 명칭이 'CASE Global Ecosystem'으로 전환되며, 글로벌 확장 전략이 본격화되었습니다.

핵심 기능

• JSON + REST API 기반 교환: CASE 프레임워크를 JSON 형식과 REST API를 통해 시스템 간 교환
• GUID 고유 식별자: 각 학습 표준·역량에 고유 식별자(GUID) 부여로 플랫폼 간 일관성 보장
• 계층적 프레임워크: 기존 PDF/Word/HTML 문서를 계층 구조의 디지털 포맷으로 변환

글로벌 확장 현황

• 미국 50개 주 커버: K-12 영어·수학 표준을 모든 주에 대해 검증·게시 완료
• PK-12+ 5개 신규 과목: 2025년 신규 교과 영역으로 확대
• 30개국+ "Core Four" 커리큘럼: 핵심 학습 성과를 30개 이상의 국가·지역에 추가

🔗 관련 링크: 1EdTech CASE 표준 | CASE Global Ecosystem | Satchel Rosetta Exchange
📊 신뢰도 평가: 8.5/10
강점: 1EdTech 공식 발표 기반의 구체적 데이터(50개 주, 30개국+), JSON/REST API 기술 상세 기술
개선점: CASE Global Ecosystem 전환의 구체적 참여 기관 수 추가 필요

전망: 2026년 CASE Global Ecosystem 출범으로 미국 중심에서 국제 표준 체계로의 전환이 가속화되고 있으며, 프랑스의 '디지털 교육 서비스 상호운용성 프레임워크' 법령처럼 국가 수준의 상호운용성 의무화가 확산되고 있습니다.

2. CLR 2.0 표준: 차세대 검증 가능한 종합 학습자 기록

현황: 2025년 3월 CLR Standard 2.0이 공식 출시되었습니다. W3C 검증 가능한 자격증명(Verifiable Credentials) 표준을 채택하여 보안성, 이식성, 검증 가능성이 크게 향상되었습니다. 학습자가 자신의 자격증명에 대한 완전한 통제권을 가지고, 원하는 시점에 원하는 곳에서 공유할 수 있게 됩니다.

CLR 2.0 주요 특징

• W3C VC 기반 보안: 위변조 방지를 위한 검증 가능한 자격증명 데이터 표준 적용
• 학습자 소유권: 학습자가 자격증명을 직접 관리·큐레이션·공유 가능
• 포괄적 기록 범위: 정규 학업, 비교과 활동, 스킬, 역량, 마일스톤 모두 포함

Open Badges 3.0과의 통합

• 배지 내 CASE GUID 임베딩: Open Badges에 CASE 식별자를 내장하여 역량 매핑 자동화
• CLR 내 배지 통합: CLR이 배지, 과정, 인증서, 비공식 학습 활동을 모두 포함
• 상호운용 에코시스템: CASE + Open Badges + CLR의 삼위일체 디지털 자격증명 체계 구축

🔗 관련 링크: 1EdTech CLR 표준 | CLR 2.0 사양서 | Open Badges 3.0
📊 신뢰도 평가: 8.0/10
강점: W3C VC 표준 채택 사실 정확, CLR 2.0 출시일(2025.3) 공식 확인, Open Badges 통합 기술 설명 명확
개선점: CLR 2.0 조기 채택 기관의 구체적 수치 보강 필요

전망: CLR 2.0은 디지털 지갑 기술과 결합하여 학습자가 평생 동안 축적한 학습·업무 성과를 안전하게 관리·공유할 수 있는 기반을 마련하고 있습니다. 고용주의 스킬 기반 채용(Skills-Based Hiring)이 확산됨에 따라 CLR의 활용 가치가 더욱 높아지고 있습니다.

3. 교육-고용 연계: LER-RS와 HR Open Standards 파트너십

현황: 1EdTech와 HR Open Standards Consortium이 공동으로 Learning and Employment Resume Standard(LER-RS)를 추진하고 있습니다. 이 표준은 Open Badges 3.0과 CLR 2.0을 기반으로 구축된 기계 판독 가능한 이력서 형식으로, 학습 기록과 채용 시스템 간의 공통 언어를 만들어 스킬 기반 채용 장벽을 해소합니다.

LER-RS 핵심 가치

• 교육-고용 가교: 배지와 CLR이 학습·역량을 기록하고, LER-RS가 채용 맥락에서 활용 가능하게 변환
• 디지털 검증 이력서: 학업 성취, 스킬, 경력 이정표를 디지털로 검증·공유 가능
• 공정성·신뢰·효율: 학습자의 검증된 성과를 고용주가 쉽게 식별

시장 데이터

• 디지털 배지 시장 성장: 2025년 $312M → 2034년 $1,195M (CAGR 15.8%) (출처: Fortune Business Insights)
• 배지 발급량 4배 증가: 2022년 7,470만 개 → 2025년 3억 2,040만 개 (출처: 1EdTech Badge Count 2025)
• 대학 94% 대체 자격증명 제공: 미국 대학·대학교의 94%가 배지·마이크로크레덴셜 제공 (출처: UPCEA 2024)

🔗 관련 링크: 1EdTech-HR Open 파트너십 | Credential Engine | T3 Innovation Network
📊 신뢰도 평가: 9.0/10
강점: Fortune Business Insights, 1EdTech Badge Count, UPCEA 등 다수의 권위 있는 출처 인용, 구체적 수치 제시
개선점: LER-RS 실제 도입 기업 사례 추가 시 더욱 강화

전망: 미국 상공회의소 재단의 T3 Innovation Network(400개 이상 기관 참여)을 통해 교육·노동·자격 데이터의 통합이 가속화되고 있으며, Credential Engine에 등록된 미국 내 고유 자격증명은 185만 개 이상(출처: Credential Engine 2025 보고서)으로 에코시스템이 급성장하고 있습니다.

4. Satchel Rosetta Exchange와 CASE 프레임워크 게시 인프라

현황: Common Good Learning Tools(CGLT)가 2026년 2월 18일 Satchel Rosetta Exchange를 업그레이드 출시했습니다. 전 세계 발행 기관이 게시한 1,000개 이상의 PK-12+ 표준·역량 프레임워크에 무료로 접근할 수 있는 가장 포괄적인 허브입니다.

Satchel 플랫폼 기능

• 1,000+ 프레임워크 미러링: 미국·국제 표준을 CASE 형식으로 미러링하여 실시간 접근
• 무료 탐색: 누구나 비용 없이 프레임워크를 검색·탐색 가능
• 자동 동기화: 발행 기관의 업데이트를 그대로 반영하는 미러 서비스

주(州) 수준 활용 사례

• 조지아: 주 교과 코드를 SOC·CIP 코드에 매핑하여 교육-경력 경로 연결
• 사우스 캐롤라이나: 역량 경로 파일럿으로 고교 교과를 노동력 스킬과 연계
• 텍사스: 텍사스 교육청(TEA)이 CASE 인증 서비스 운영

🔗 관련 링크: Satchel Rosetta Exchange | Common Good Learning Tools | EdGate CASE 서비스
📊 신뢰도 평가: 7.5/10
강점: Satchel 출시일(2026.2.18), 1,000+ 프레임워크 수치 명시, 3개 주의 구체적 활용 사례 제시
개선점: 에코시스템 자동화 전망에 대한 EdTech 기업의 도입 사례나 수치 근거 추가 필요

전망: CASE 프레임워크의 게시 인프라가 성숙해지면서, 교과서 출판사, LMS, 학습 객체 저장소(LOR) 등의 EdTech 플랫폼들이 CASE API를 통해 표준 데이터를 직접 소비하는 자동화된 생태계가 형성되고 있습니다.

5. 대학 CLR 도입 사례: IUPUI, 미주리 대학, WGU의 혁신적 접근

현황: AACRAO와 NASPA가 Lumina Foundation의 지원을 받아 다수의 대학에서 CLR 파일럿 프로젝트를 진행하고 있으며, 각 기관이 고유한 접근 방식으로 종합 학습자 기록을 구현하고 있습니다.

주요 대학 구현 사례

• IUPUI: Lumina Foundation 지원으로 CLR 모델 개발·구현, 체험 학습 기반의 풍부한 학습 이력 기록
• 미주리 대학(MU): CLR 비전·목적 정의, 캠퍼스 목표와 정렬된 프레임워크 개발, 플랫폼·데이터 통합 식별
• 노스텍사스 대학(UNT): Parchment 디지털 배지 기반 CLR 도입, 시장성 있는 스킬을 배지·자격증 형태로 수집

WGU Achievement Wallet

• 학습자 소유 LER: Western Governors University가 전국 학생에게 Learning and Employment Record 제공
• Achievement Wallet 배포: WGU 학생 및 인디애나 주 내 교육기관 재직 학생 대상
• CTDL 연동: Credential Transparency Description Language 정보로 과정 수준 성취 발급

🔗 관련 링크: Parchment CLR Services | NASPA CLR 프로젝트 | 미주리 대학 CLR
📊 신뢰도 평가: 7.5/10
강점: IUPUI, MU, UNT, WGU 4개 대학의 구체적 구현 사례, Lumina/Gates Foundation 지원 금액 명시
개선점: CLR 도입 후 학습자 성과(취업률, 학점 이동 성공률 등) 정량적 데이터 보강 필요

전망: AACRAO-Parchment CLR Services 파트너십과 Bill & Melinda Gates Foundation의 $120만 추가 지원으로 학점 이동성(Credit Mobility) 실현이 가속화되고 있으며, 대학별 맞춤형 CLR 구현 모델이 표준 사례로 확산되고 있습니다.

경쟁 환경과 시장 포지셔닝

4층 에코시스템 구조

1EdTech의 CASE & CLR 에코시스템은 표준 정의, 인프라 제공, 플랫폼 소비, 최종 활용의 4개 층으로 구성됩니다.

계층 역할 주요 플레이어 대상
표준 정의 기관 CASE/CLR/OB 표준 개발 1EdTech, W3C, HR Open Standards 전 산업
인프라 제공자 프레임워크 게시·배포 Satchel/CGLT, EdGate, Credential Engine 교육 기관·출판사
플랫폼 소비자 CASE/CLR 데이터 통합 Canvas, Schoology, PowerSchool, Parchment 학교·대학
최종 활용자 자격증명 발급·검증·활용 Credly, WGU, Territorium, HelioCampus 학습자·고용주

시장 트렌드

• 디지털 배지 시장이 2025년 $312M에서 2034년 $1,195M으로 CAGR 15.8% 성장 전망 (출처: Fortune Business Insights)
• 교육용 디지털 배지 시장은 2024년 $1.62B에서 2034년 $6.84B으로 CAGR 15.5% 성장 예상 (출처: Market.us)
• 1EdTech 배지 발급량이 2022년 7,470만 개에서 2025년 3억 2,040만 개로 4배 이상 증가
• 미국 내 134,000개 이상 기관이 185만 개 고유 자격증명을 제공 (출처: Credential Engine 2025)
• CASE-CLR-Open Badges 삼위일체 체계가 교육-고용 연계의 표준 인프라로 부상

주요 플랫폼 역량 비교

활용 아이디어

글로벌 사례에서 관찰되는 주요 활용 접근 방식을 소개합니다.

1. 교육-경력 경로 매핑 - 조지아·사우스 캐롤라이나처럼 CASE로 학교 교과 코드를 직업 표준(SOC/CIP)에 매핑하여 K-12부터 노동시장까지 일관된 스킬 추적 체계 구축

2. CLR 기반 포괄적 학생 이력 관리 - WGU Achievement Wallet 모델을 참고하여 학업·비교과·인턴·자격증을 CLR 2.0으로 통합 관리하고 디지털 지갑을 통해 학습자가 직접 큐레이션·공유

3. LMS-CASE API 표준 정렬 자동화 - Canvas·Schoology 등 LMS에 CASE API를 연동하여 교과서·학습 리소스를 학습 표준에 자동 정렬하고 역량 기반 보고 체계 구현

에그제큐티브 서머리

핵심 인사이트

  • 삼위일체 에코시스템 완성: CASE 1.1, CLR 2.0, Open Badges 3.0의 세 가지 표준이 교육-고용 연계의 상호운용 가능한 기반 인프라를 형성. CASE가 역량 맥락을, Open Badges가 개별 성취를, CLR이 종합 내러티브를 담당
  • 글로벌 확산 가속: 미국 50개 주 K-12 표준 게시 완료, 30개국+ Core Four 커리큘럼 추가, 프랑스의 상호운용성 의무화 법령 등 국가 수준의 정책적 지원 확대
  • 스킬 기반 채용의 현실화: LER-RS를 통한 교육 자격증명의 채용 시스템 직접 연동이 가능해지면서, 학위보다 검증된 스킬과 역량이 중시되는 노동시장 패러다임 전환 진행 중
  • 대학 CLR 도입 모멘텀: Lumina Foundation, Gates Foundation 등의 지원으로 IUPUI, WGU, 미주리 대학 등 선도 대학의 CLR 파일럿이 산업 표준 사례로 확산
  • 배지 시장 폭발적 성장: 2022-2025년 배지 발급량 4배 증가(7,470만→3억 2,040만), 미국 대학 94%가 대체 자격증명 제공 중

고등교육 기관 → CLR 2.0 기반 종합 학습자 기록
근거: Parchment CLR Services, AACRAO 컨설팅 파트너십 활용 가능, W3C VC 기반 검증으로 학점 이동성 실현

기업·HR 부서 → LER-RS 기반 스킬 기반 채용

주요 용어 설명

CASE (Competency and Academic Standards Exchange) - 학습 표준, 역량, 학습 성과를 기계 판독 가능한 디지털 형식으로 교환하기 위한 1EdTech의 개방형 기술 표준. JSON과 REST API를 사용하며 각 역량에 GUID를 부여합니다.
CLR (Comprehensive Learner Record) - 학습자의 전체 학습 여정을 디지털로 기록하는 종합 학습자 기록 표준. 정규 학업 성과뿐 아니라 비교과 활동, 스킬, 역량, 경력 이정표를 포함합니다.
Open Badges 3.0 - W3C 검증 가능한 자격증명(Verifiable Credentials)을 채택한 디지털 배지 표준. 학습 성취를 시각적·검증 가능한 형태로 인증하며, CASE GUID를 임베딩하여 역량과 연결합니다.
LER-RS (Learning and Employment Resume Standard) - HR Open Standards와 1EdTech가 공동 개발한 기계 판독 가능한 이력서 표준. Open Badges와 CLR을 채용 시스템에서 활용 가능하게 하는 가교 역할을 합니다.
GUID (Globally Unique Identifier) - CASE 프레임워크에서 각 학습 표준·역량에 부여되는 고유 식별자. 서로 다른 시스템 간에 동일한 역량을 정확히 참조할 수 있게 합니다.
W3C Verifiable Credentials - 월드와이드웹 컨소시엄(W3C)이 정의한 디지털 자격증명 데이터 표준. CLR 2.0과 Open Badges 3.0이 이 표준을 채택하여 위변조 방지와 검증 가능성을 보장합니다.
CTDL (Credential Transparency Description Language) - Credential Engine이 개발한 자격증명 투명성 기술 언어. CLR과 호환되며 자격증명의 상세 정보(스킬, 조건, 비용 등)를 구조화하여 기록합니다.
