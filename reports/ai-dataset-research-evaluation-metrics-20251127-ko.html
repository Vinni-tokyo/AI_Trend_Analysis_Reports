주요 트렌드 Top 5

1. 고전적 벤치마크 데이터세트의 진화와 한계

현황: MNIST는 1999년 Yann LeCun 등이 개발한 손글씨 숫자 데이터세트로, 머신러닝의 "Hello World"로 알려져 있습니다. 그러나 2024년 최첨단 슈퍼컴퓨터와 알고리즘으로는 MNIST가 "해결됨" 상태로 간주되며, 대부분의 모델이 95% 이상의 정확도를 쉽게 달성합니다. CIFAR-10/100은 MNIST와 ImageNet 사이의 "가교" 역할을 했지만, 이 역시 한계가 드러나고 있습니다.

고전적 데이터세트

• MNIST: 60,000 훈련 이미지, 10,000 테스트 이미지, 10개 카테고리
• CIFAR-10: 60,000장 32×32 픽셀, 10개 카테고리
• ImageNet: 1,400만 장 이상, 20,000개 이상 카테고리

대안·확장 데이터세트

• Fashion-MNIST: MNIST 직접 대체, 10개 패션 카테고리
• EMNIST/KMNIST: Extended/Kuzushiji MNIST
• ObjectNet: 테스트 전용, 훈련 데이터 없음

🔗 관련 링크: MNIST | CIFAR | ImageNet | Fashion-MNIST

전망: 지속 학습(Continual Learning) 연구에서는 MNIST/SVHN/ImageNet/CIFAR10과 같은 단일 개념 세트에 국한되지 않는, 이종 태스크를 포함하는 벤치마크가 요구되고 있습니다. 흑백에서 RGB로, 다양한 이미지 크기, 개념 수 변화에 대응할 수 있는 모델 개발이 가속화되고 있습니다.

2. LLM 훈련 데이터세트의 대규모화와 큐레이션

현황: RedPajama-V2는 30조 토큰을 포함하는 최대 규모의 공개 LLM 훈련 데이터세트입니다. 84개의 CommonCrawl 스냅샷에서 1,000억 개 이상의 텍스트 문서를 수집하고, 40개 이상의 품질 어노테이션을 사전 계산했습니다. 영어, 프랑스어, 스페인어, 독일어, 이탈리아어 5개 언어를 지원합니다.

RedPajama-V1 구성 (1.2조 토큰)

• CommonCrawl: 8,780억 토큰
• C4: 1,750억 토큰
• GitHub: 590억 토큰
• Books/ArXiv/Wiki: 780억 토큰

2025년 트렌드

• 중복 제거 고도화: DeepSeek은 20-30% 중복 데이터 제거
• 양보다 질: 소수의 다양한 토큰 중시
• FineWeb-Edu: 교육 콘텐츠 특화 1.3조 토큰

🔗 관련 링크: RedPajama-V2 | CommonCrawl | FineWeb-Edu

전망: Common Corpus는 윤리적 LLM 사전 학습을 위한 최대 컬렉션으로 주목받고 있습니다. YouTube Commons에서 FineVideo(43,000개 동영상)와 Mosel(100만 오디오 시간) 등 멀티모달 데이터세트가 파생되고 있습니다.

3. 멀티모달·추천 시스템 데이터세트

현황: LAION-5B는 58.5억 개의 이미지-텍스트 쌍을 포함하는 거대한 멀티모달 데이터세트로, Stable Diffusion이나 DALL·E 같은 텍스트-이미지 생성 모델 훈련에 사용됩니다. 추천 시스템에서는 MovieLens(1997년 설립)가 협업 필터링의 골드 스탠다드로 널리 사용되고 있습니다.

멀티모달 데이터세트

• LAION-5B: 58.5억 이미지-텍스트 쌍
• COCO: 32.8만 이미지, 250만 라벨
• Google Open Images V6: 최신 버전, 관계·세그멘테이션

추천 시스템 데이터세트

• MovieLens: 10만~2,500만 평점, 32회 이상 논문 사용
• Amazon Reviews: 24편 논문 사용, 다중 카테고리
• Netflix Prize/Last.fm/Yelp: 대표적 벤치마크

🔗 관련 링크: LAION | COCO | MovieLens

전망: 추천 시스템의 주요 과제로 데이터 희소성, 확장성, 다양한 추천의 필요성이 꼽히고 있습니다. 협업 필터링의 "콜드 스타트" 문제(신규 아이템/사용자 대응) 해결을 위한 하이브리드 접근 방식이 2024년 연구에서 활발해지고 있습니다.

4. NLP 벤치마크의 진화: GLUE에서 BIG-Bench까지

현황: GLUE(General Language Understanding Evaluation)는 자연어 이해 시스템의 훈련·평가·분석을 위한 리소스 모음입니다. 2019년 GLUE가 "해결"됨에 따라 동일 팀이 더 어려운 SuperGLUE를 발표했습니다. 주목할 점은 DeBERTa-v3가 PaLM의 1/360 크기로 SuperGLUE를 능가했다는 것으로, 아키텍처와 사전 학습 기술의 중요성을 보여줍니다.

주요 NLP 벤치마크

• GLUE: 문장 수준 태스크 중심, NLU 표준
• SuperGLUE: 상호 참조 해결, QA, 장문 추론
• MMLU: 인문·사회·STEM 전 분야 지식 평가

신세대 벤치마크

• BIG-Bench: 200개 이상 태스크, 기존 NLP 초월
• MMMLU: 14개 언어 전문 번역 버전
• CMMLU: 중국어 버전, 67개 과목 1,528문제

🔗 관련 링크: GLUE | SuperGLUE | BIG-Bench | MMLU

전망: 언어 모델의 복잡화에 따라 ROUGE나 BLEU 점수만으로는 능력을 포착할 수 없게 되었습니다. 도메인 특화 벤치마크(의료용 BLUE, 법률용 LexGLUE), 동적·멀티모달·프라이버시 보호 벤치마크가 향후 트렌드입니다.

5. 합성 데이터 생성의 폭발적 성장

현황: 2024년 AI/ML 훈련에서 합성 데이터 시장 점유율은 30% 이상을 차지하며, 시장 규모는 약 3.1억 달러로 평가됩니다. 2034년까지 CAGR 35.2%로 성장이 예측됩니다. 2025년에는 합성 데이터 생성이 실험적 역량이 아닌 운영상 필수 요소가 되었습니다.

주요 생성 방법

• GAN: 실제적인 이미지·음성·행동 생성
• 확산 모델: 이미지를 넘어 구조화 데이터 생성
• LLM: 텍스트·대화·문서 생성

산업 응용

• 의료: 익명화 환자 기록으로 진단 AI 훈련
• 자율주행: 드문 중요 운전 이벤트 시뮬레이션
• 금융: 사기 탐지용 합성 신용카드 거래

🔗 관련 링크: Synthetic Data Survey | CVPR 2025 Synthetic Data Workshop

전망: LLM 기반 데이터 증강이 2024-2025년 주요 트렌드입니다. 과제로는 합성 데이터와 실세계 데이터의 "도메인 갭", 바이어스 전이, 품질 유지가 남아 있습니다. 의료·금융 분야에서는 규제 준수를 위한 합성 데이터의 신중한 검증이 필요합니다.

데이터세트 평가 메트릭 심층 분석

공정성·바이어스 메트릭

공정성 평가를 위한 5가지 주요 메트릭이 확립되어 있습니다: Equalized Odds(EO), Equality of Opportunity, Demographic Parity(DP), Individual Differential Fairness, MDFA입니다.

메트릭명 정의 적용 장면
Demographic Parity (DP) 결정이 민감한 속성과 무관함을 보장 채용, 대출 결정
Equalized Odds (EO) 양성·음성 평가 간 공정성 보장 의료 진단, 리스크 평가
Equality of Opportunity 동일 기준 충족 개인의 동등한 대우 교육, 승진 결정
Individual Differential Fairness 유사 개인 간 공정한 예측 개인화 서비스
MDFA 다차원 공정성 평가 복합 속성 분석

데이터 품질·가치 평가 메트릭

데이터 중심 AI(Data-Centric AI) 접근 방식으로서, Data Shapley는 데이터 기반 학습 알고리즘에서 개별 데이터 튜플의 중요성을 정량화하고, 모델 전체 성능에 대한 기여도로 품질과 가치를 식별합니다.

방법 특징 계산 복잡도
Data Shapley 게임 이론 기반, 개별 데이터 기여도 평가 O(2^N) → 개선 버전 O(N log N)
CHG Shapley (ICLR 2025) 폐쇄형 Shapley 값, 단일 모델 재훈련으로 계산 이차 개선
Unlearning Shapley (2025) 기계 언러닝 활용, 재훈련 불필요 몬테카를로 샘플링
Chunked Data Shapley 대규모 데이터세트 품질 평가, 6차원 품질 분류 스케일러블

데이터 품질의 6가지 차원 (Mohammed et al., 2025a): 표현성, 완전성, 특성 정확도, 타겟 정확도, 고유성, 타겟 클래스 균형

LLM 바이어스 벤치마크

AI 공정성 연구자들은 데이터세트와 관련 메트릭을 포함하는 벤치마크를 만들어 AI 공정성의 특정 차원을 측정하고 있습니다. BBQ(Bias Benchmark for QA)는 객관식 문제를 사용하여 언어 모델의 다양한 인구 통계 그룹에 대한 바이어스를 측정합니다.

벤치마크 측정 대상 카테고리
BBQ 인구 통계 그룹 바이어스 연령차별, 인종차별, 성차별 등
Sony FHIBE 인구 통계·물리적 속성, 환경 요인 81개국/지역, 10,318개 이미지
Parity Benchmark LLM 바이어스 정량화 식민주의, 컬러리즘, 동성애 혐오

활용 아이디어

시장에서 관찰되는 주요 활용 접근 방식을 소개합니다.

1. Data Shapley를 활용한 데이터 품질 감사 - 훈련 데이터의 기여도를 정량화하고, 저품질 데이터 자동 식별·제거로 모델 성능 향상

2. AI Fairness 360을 활용한 바이어스 탐지 파이프라인 - 채용·대출 모델의 공정성 메트릭 측정 및 완화 알고리즘 적용

3. 합성 데이터 생성을 통한 훈련 데이터 확장 - 프라이버시를 보호하면서 희귀 시나리오(의료 진단, 사기 탐지)의 데이터 증강

에그제큐티브 서머리

핵심 포인트

  • 고전적 벤치마크의 한계: MNIST는 "해결됨" 상태, 지속 학습용 이종 태스크 벤치마크 필요
  • LLM 데이터세트 대규모화: RedPajama-V2(30조 토큰), 품질 어노테이션 중시로 전환
  • 합성 데이터 시장 급성장: 2024년 시장 점유율 30% 이상, 2034년까지 CAGR 35.2% 성장 전망
  • 공정성 평가 표준화: 5가지 주요 메트릭 확립, AI Fairness 360 등 툴킷 보급
  • Data Shapley 실용화: 계산 효율 개선(O(2^N)→O(N log N))으로 대규모 데이터세트 평가 가능

용도별 권장

컴퓨터 비전 연구 → Fashion-MNIST, COCO, ObjectNet(테스트 전용)
이유: MNIST 한계 극복, 실세계에 가까운 벤치마크

LLM 훈련 → RedPajama-V2, FineWeb-Edu(교육 특화)
이유: 품질 어노테이션 포함, 중복 제거 완료

공정성 평가 → AI Fairness 360 + Sony FHIBE
이유: 포괄적 메트릭, 글로벌 다양성

종합 평가: 긍정적 (데이터 중심 AI 패러다임 확립과 평가 방법론의 성숙화 진행 중)

핵심 용어 설명

Data Shapley - 게임 이론의 Shapley 값을 응용하여 각 훈련 데이터가 모델 성능에 얼마나 기여하는지 정량화하는 방법
Demographic Parity - AI 결정이 인종·성별 등 민감한 속성과 통계적으로 무관할 것을 요구하는 공정성 기준
CommonCrawl - 공개된 웹 크롤 아카이브로, LLM 훈련의 주요 데이터 소스. 단, 원시 데이터는 노이즈가 많아 전처리 필요
지속 학습(Continual Learning) - 새로운 지식을 습득하면서 과거 지식을 잊지 않도록 학습하는 ML 연구 분야
합성 데이터(Synthetic Data) - 실제 데이터가 아닌 알고리즘(GAN, 확산 모델, LLM)으로 생성된 데이터. 프라이버시 보호나 데이터 부족 해소에 유효
GLUE/SuperGLUE - 자연어 이해 능력을 평가하기 위한 벤치마크 스위트. SuperGLUE는 GLUE "해결" 후 발표된 더 어려운 버전
