バッジのプラットフォームはすでに推薦をしている
— 分かれ目は誰が費用を払うかだ

Accredible・Credly・Europass の取得者向け推薦を、財源と範囲で並べて見ます
レポート作成日：2026年11月18日 | 標準レポート（5-8ページ） | データ収集：2026年11月18日

主要トレンド Top 5

このレポートの中心となる主張
「バッジのプラットフォームは発行するだけで、推薦はしない」という見方は、もう当てはまりません。 Accredible、Credly、Europass はいずれも、バッジの取得者に仕事や講座を推薦しています。 したがって問うべきは推薦があるかどうかではなく、その推薦が誰のお金で、どの範囲の中で動いているかです。 民間の2社では発行機関が費用を負担し、推薦は自社のネットワークの中で動きます。Europass は公的な財源で、欧州の中で動きます。 そして日本と韓国では、取得者に推薦を行うバッジのサービスを見つけられませんでした。

1. Accredible Career Journey — バッジから始まる無料のキャリア案内

現状：Accredible は2026年4月30日に「Career Journey」を公開しました（告知記事は7月3日に更新）。 取得者が受け取った資格証明を出発点とする無料のキャリア案内で、アプリの導入も別途の登録も要らないと説明しています。

取得者が入れるものと受け取るもの

• 入力：いま見ている資格証明に加えて、職歴、学歴、現在の職務、希望する職務、目標、地域
• スキルの言い換え：履歴書の文、LinkedIn の紹介文、面接で話す材料
• 関連する職務：「実際の給与の幅、需要の動き、採用中の企業のデータ」とともに提示
• 次の一歩：講座、職務、目標のうち一つを具体的に提案

発行機関から見た姿

• 設定は不要：発行機関が何も作らなくても、自らの資格証明にキャリア案内が付きます
• 露出：「貴機関のプログラムが自然な次の段階として現れる」。同社はこれを「広告ではなく関連性に基づく」と説明しています
• データ：自機関の受領者の行動・利用データを第3四半期に提供すると予告
• 規模：毎月50万件以上を発行、累計1億8,500万件以上（同社発表）

🔗 関連リンク: Career Journey の告知 | Accredible

展望：同社が根拠として挙げているのは自社の調査です。2025年の調査で、取得者の76.8%が、資格証明を受け取った時点でそれが仕事やキャリアの機会とどうつながるかを見たいと答えたといいます。 発行プラットフォームが「発行のあと」を製品として作り始めた兆しと読めます。ただし、給与や需要のデータの出どころは告知に書かれていません。

📊 信頼性評価: 7/10
強み：公開日、入力、出力、発行機関の利点は同社の公式告知で直接確認しました。引用した文言は原文どおりです。
改善点：🔴 すべて提供元自身の説明です。実際の画面は使っておらず、76.8%は標本も方法も公開されていない自社調査の数値です。提供地域、対応言語、労働市場データの出どころ、利用者数は告知にありません。

2. お金の流れ — 推薦の枠を買うのは発行機関である

現状：Accredible には、Career Journey より前に出た「Recommendations」（2022年9月公開）があります。 利用規約（2022年7月7日更新）を読むと、これは発行機関どうしが互いの資格証明ページに自らの講座を広告として載せるネットワークです。

規約が示す仕組み

• 誰が払うか：広告を出す発行機関。課金の指標は「表示またはクリック」
• 初期設定で参加：「ネットワークプール」への参加が初期設定で、抜けるには10日前の書面通知が必要です
• 優先表示：「優先配置」を購入できます。順位や位置は保証されず、選ばれ方の説明はありません
• 収益の分配：自らのページに載った他機関の広告から収益を得る選択肢（承認が必要）

同じ会社のほかの商品

• 配信の基準：閲覧中のページの内容など「個人を特定しない基準」による文脈ターゲティング
• Pathways：発行機関が設計する学習経路。同社は新規の受講登録が「最大367%」増えたと主張しています（方法は非公開）
• Spotlight Directory：発行機関の契約に付ける有料の追加商品で、人材の名簿です
• 基本料金：発行機関が受領者数に応じて年単位で支払います。取得者は無料

🔗 関連リンク: Recommendations 利用規約 | Pathways | Accredible 料金

展望：取得者は無料で発行機関が支払う仕組みでは、推薦が精緻になるほど「なぜこの講座が自分の次の段階として出てきたのか」という問いが付いて回ります。 Career Journey は「広告ではなく関連性に基づく」と述べていますが、同じ会社が優先配置を売る商品も運営しています。 二つの商品が実際につながっているかどうかは、公開資料では確認できません。確認できないという事実そのものが、この項目の要点です。

📊 信頼性評価: 7/10
強み：課金の指標、初期設定での参加、優先配置、収益の分配は規約の原文で確認しました。法的な文書なので、宣伝文より信頼できます。
改善点：🔴 規約は2022年版で、現在の運用が同じかどうかは確認できていません。クリック単価と Accredible の取り分は非公開です。「367%」は提供元の主張です。Recommendations と Career Journey のつながりは本分析が確認できなかった点です。

3. Credly — 職業に基づく推薦と求人への接続

現状：Pearson 傘下の Credly は、バッジ1億個、取得者4,800万人以上、発行機関4,000以上を抱える最大手です（2025年1月、Pearson 発表）。 取得者向けの管理画面を作り直して推薦を前面に出し、すべての資格証明ページに求人を付けました。

取得者の画面

• ホーム：プロフィール、バッジ、スキルに加えて、職業に基づくバッジの提案、人気のバッジ、個人に合わせたバッジ・スキルの推薦
• 探索（Explore）：上位のスキル、伸びているスキル、職業に基づく推薦はこちらに移りました
• 位置づけ：推薦はあくまで提案であり、要件ではないと案内しています
• 関連する求人：各資格証明ページの「Related Jobs」で検索・絞り込み

労働市場のデータ

• 出どころ：「世界の25,000以上の求人サイトと企業の採用ページ、米国国勢調査局、労働統計局」
• 更新：常時更新し、有効な求人だけを表示すると説明しています
• 検索の軸：職名、地域、雇用主、給与の幅
• 対象：取得者と発行機関の両方。「プラットフォームの誰もが利用できる」

🔗 関連リンク: Credly Labor Market Insights | 新しい取得者向け画面の案内 | Credly

展望：Credly の推薦は職業と人気の動きから出発します。取得者が目標を決めると、足りないスキルを示し、学ぶ順序を組み立ててくれるという流れは、公開資料では確認できませんでした。 また、この推薦は Credly の中で動きます。取得者向けの規約（2023年7月版）はスクリプト、ロボット、クローラーの使用とデータの収益化を禁じており、API の認証は組織単位なので、取得者が自分の履歴を第三者に渡すための同意の仕組みがありません。

📊 信頼性評価: 6/10
強み：労働市場データの出どころと検索の軸は Credly の製品ページで、規模の数値は Pearson の公式発表で確認しました。
改善点：🔴 管理画面のヘルプ記事は直接開けず（403）、検索結果の要約に基づいています。更新日の表記も形式があいまいです。「目標→不足→順序」がないというのは公開資料で見つからなかったという意味で、機能がないことの証明ではありません。企業向けの Talent Match は二次資料が一つしかないため、本文から外しました。

4. Europass — 公共が運営する推薦

現状：欧州委員会が運営する Europass は、2025年7月時点で登録利用者850万人以上、31言語に対応する無料のプラットフォームです。 プロフィールに書いたスキルと関心をもとに、仕事と講座を提案します。

提案が作られる仕組み

• 入力：プロフィールと「My skills」「My interests」に書いた内容。機能を有効にすると、提案が画面に表示されます
• スキルの辞書：欧州の標準分類 ESCO。スキルの提案は、ポートフォリオの内容の分析と利用者どうしの類似性から生成されると説明されています（2024年5月の発表資料）
• 求人：EURES を通じて「スキルと関心に合わせた300万件以上の求人」
• 人による支援：31か国に約1,000人の EURES アドバイザー

ウォレットと今後の計画

• ウォレット：機関が欧州学習デジタル資格証明（EDC）を送ると、ライブラリ内のウォレットに入ります
• 道具：履歴書・カバーレターの編集、デジタルスキルの自己診断、応募の管理、面接の準備
• 予告：特定の求人に合わせて関連するスキルを選び出す「Smart CV」など、AI の活用
• 財源：公的資金。取得者も発行機関も推薦にお金を払いません

🔗 関連リンク: Europass | EURES | ESCO

展望：Europass には費用を払う発行機関がいないので、利益相反から最も自由です。 その代わり、対話型のコーチングではなくプロフィールに基づく提案であり、求人とのつながりは欧州の労働市場（EURES）に限られます。 欧州委員会自身が2023年に「個別の提案と個人化をさらに改善中」と書いているため、現在の機能の水準は実際のポータルで確かめる必要があります。

📊 信頼性評価: 7/10
強み：利用者数、対応言語、提案の入力、EURES との接続は、EU の公式ページ（Europass・EURES）で確認しました。
改善点：ESCO と利用者の類似性についての説明は2024年の発表資料に基づいており、現行の実装と同じかどうかは確認できていません。発行された EDC の数は見つかりませんでした。「コーチングではない」は本分析の解釈です。

5. ネットワークの境界と地域の空白 — 推薦が届かない場所

現状：三つのサービスの推薦は、それぞれの囲いの中で動いています。囲いを越えるための標準（Open Badges 3.0）はまだ発行量が少なく、 日本と韓国では、取得者に推薦を行うバッジのサービスを見つけられませんでした。

囲いを越える道

• 標準の現在地：1EdTech の2025年の集計では、授与されたバッジ3億2,050万個のうち Open Badges 3.0 は270万個です
• Accredible：2026年1月13日、OB 3.0 と W3C VC の書き出しと取り込みへの対応を発表。「ほかの発行機関の検証可能な資格証明をウォレットに取り込める」
• Credly：取得者はバッジを一つずつダウンロードできますが、第三者が同意を得て履歴を受け取るための API はありません
• 欧州：LinkedIn はデジタル市場法に基づき、欧州経済領域の会員に限って第三者向けのデータ移行 API を開いています

日本と韓国

• 日本：発行バッジ208万個、会員組織373（2025年10月、二次資料）。世界の集計の1%に届きません
• 韓国：全国の集計は見つかりませんでした。ある教員向けバッジ事業が2023年の2,301件から2025年上半期の65,173件に増えたという報道があります
• 推薦：両国のバッジのプラットフォームやウォレットで、取得者向けの推薦機能は見つかりませんでした
• 言語：Career Journey と Credly の対応言語は公式資料に明記されていません

🔗 関連リンク: 1EdTech Badge Count 2025 | Accredible OB 3.0 対応の発表 | Open Badges 3.0 仕様

展望：複数の場所で得たバッジをまとめて扱う推薦は、標準が広がってはじめて容易になります。Accredible の取り込み対応はその方向への第一歩ですが、 OB 3.0 の発行量が全体の1%前後にとどまる現在は、取得者が自分でファイルを上げるかリンクを渡す方法が現実的な道です。 日本と韓国の空白は「ない」ではなく「見つからなかった」と読むべきです。

📊 信頼性評価: 5/10
強み：世界のバッジ数と OB 3.0 の発行量は 1EdTech の集計で、Accredible の取り込み対応は同社の報道発表で確認しました。
改善点：🔴 日本と韓国の「推薦なし」は不在の証拠にとどまり、全数調査ではありません。日本の数値は財団の数値を引用した二次資料で、韓国は全国の集計がないため一つの事業の報道に頼りました。1EdTech も、年ごとの数値は厳密には比較できないと述べています。

競争環境と市場ポジショニング

3層の構造 — 財源と範囲で分ける

取得者向けの推薦を「誰が費用を払うか」と「どの範囲の資格証明の上で動くか」で分けると、三つの層になります。この区分は本分析の提案です。

サービス 層 取得者向けの推薦 推薦の入力 費用を払う側 範囲
Accredible 発行機関が負担・民間 Career Journey、Recommendations、Pathways 資格証明＋職歴・希望職務・地域 発行機関（受領者あたりの年額＋広告） 自社ネットワーク、OB 3.0 の取り込みに対応
Credly（Pearson） 発行機関が負担・民間 職業に基づくバッジ・スキルの推薦、関連する求人 保有バッジ＋職業＋人気の動き 発行機関（見積もり） 自社ネットワーク
Europass 公的財源 仕事・講座の提案 プロフィール＋スキル＋関心 欧州連合 欧州（EURES・ESCO）
Canvas Credentials（旧 Badgr） ほぼ発行専用 機関が設計する経路。個人の目標に基づく推薦は見つからず — 機関 複数の出どころのバッジを経路に積める
Open Badge Factory 発行専用 見つからず — 発行機関（年220〜1,280ユーロ） 自社ウォレット（Open Badge Passport）
Certifier、Sertifier 発行専用 見つからず — 発行機関（月額契約） 自社
日本・韓国のバッジのプラットフォーム 発行専用 見つからず — 発行組織 国内

公表されている規模の数値

それぞれの数値は、発表した主体、基準となる時点、数える単位（バッジ・資格証明・利用者）が異なります。足し合わせたり、市場占有率として読んだりすることはできません。1EdTech の集計は24のプラットフォームの合計です。

市場の五つの変化

  • 発行から「発行のあと」へ：大手のプラットフォームが、取得者の画面にキャリアや求人の機能を加えています。
  • 取得者は無料、発行機関が支払う：民間の2社はどちらも、推薦の費用を取得者に求めていません。そのぶん、推薦の中立性は規約と運用のしかたに左右されます。
  • 労働市場データとの結合：給与、需要、採用企業の情報がバッジの横に並び始めました。Credly は出どころを明らかにしており、Accredible の告知には出どころがありません。
  • 標準を通じた取り込みの始まり：OB 3.0 と VC の取り込みが始まり、「自社ネットワーク」の境界が少しずつ薄れています。ただし発行量はまだ全体の1%前後です。
  • 地域の偏り：推薦の機能は北米と欧州の事業者に集まっており、日本と韓国では確認できませんでした。

活用アイデア

市場で観察される主要な活用アプローチをご紹介します。

1. まず財源を確かめる - 推薦のサービスを比べるとき、機能の一覧より先に「誰が費用を払うか」「優先表示を買えるか」を書き出してみる

2. 取得者が自分で渡す経路を調べる - バッジのファイルの登録、共有リンク、OB 3.0 ウォレットの提示など、取得者自身が渡す方法がどこまで使えるかを確かめる

3. 地域のデータとの接続を点検する - 仕事や講座の推薦が、対象地域の求人情報と職業分類につながっているかを見てみる

エグゼクティブサマリー

重要なポイント

  • 推薦はすでにあります：Accredible（Career Journey、2026年4月）、Credly（職業に基づく推薦と関連する求人）、Europass（仕事・講座の提案）は、いずれもバッジの取得者に推薦を行っています。
  • 分かれ目は財源です：民間の2社では発行機関が支払い、取得者は無料です。Accredible の規約には、発行機関が表示またはクリックに応じて課金され、優先配置を購入できると書かれています。
  • 範囲は自社ネットワークです：Credly は取得者の同意に基づく API を第三者に開いておらず、自動収集を規約で禁じています。Accredible は2026年1月から、ほかの発行機関の OB 3.0・VC の取り込みに対応しています。
  • 公共のモデルが別にあります：Europass は850万人以上に無料で提案を届けており、利益相反が最も少ない形です。その代わり、欧州の労働市場に限られます。
  • 日本と韓国は空いて見えます：両国で取得者に推薦を行うバッジのサービスは見つかりませんでした。全数調査ではないので、「ない」ではなく「見つからなかった」です。

状況別の参考

バッジを発行する機関であれば → プラットフォームの推薦ネットワークへの参加条件を読んでみてください
理由：初期設定で参加になっている場合があり、自機関の受領者のページにほかの機関の講座が載ることがあります。
推薦のサービスを作ろうとする組織であれば → まずデータを受け取る道を確かめてください
理由：大手のプラットフォームにある履歴は、取得者が自分で渡す方法以外では受け取りにくいのが実情です。機能より先に、取り込みの経路で行き詰まります。
バッジを持つ個人であれば → 推薦の横に「提携」の表示があるかを見てください
理由：推薦の枠を発行機関が買える仕組みでは、何が関連性で出てきて何が契約で出てきたのかが画面に示されていてこそ、判断できます。

総合評価：やや肯定的な中立。バッジが「受け取って終わるもの」から「次の一歩につながるもの」へ変わっていく流れは、取得者にとって有益です。ただし、推薦を誰が買っているのか、どのデータで給与や需要を語っているのかは十分に公開されておらず、この流れはまだ英語圏と欧州にとどまっています。

📋 総合信頼性評価

6.4/10

総合評価：三つのサービスの機能、財源、規模は、各社と EU の公式ページで直接確認しました。その上に置いた「3層」の区分と利益相反についての解釈は、本分析の提案です。
