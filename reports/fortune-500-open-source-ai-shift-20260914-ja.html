フォーチュン500の半数がオープンソースAIへ？ —
その数字が実際に測ったもの

Hugging Face の主張と正反対を指すデータ、そしてオープンな重みの主導権の移動
レポート作成日：2026年9月14日 ｜ 標準版レポート（5-8ページ）

主要トレンド Top 5

1. 発端 — 「フォーチュン500の半数」は何を数えた数字か

現状：2026年7月10日、TechCrunch のポッドキャスト Equity において、Hugging Face の最高経営責任者クレマン・ドゥラング氏が「フォーチュン500企業のおよそ半数が、Hugging Face を通じてオープンソースモデルや自社モデルを配備している」と述べました。示された移行の道筋は単純です。企業は OpenAI や Anthropic の最先端 API から始めるものの、利用が増えるほどトークン費用が重くなり、より安く制御しやすいオープンなモデルへ移っていく、という説明です。同社の規模はモデル300万点以上、データセット50万点、アプリ100万点、開発者1,800万人、法人顧客20万社です。

主張の出どころと規模

• 発言：2026-07-10 TechCrunch Equity（記者 Rebecca Bellan）
• 論理：最先端APIで開始 → 規模が大きくなると費用がオープンモデルへ押し出す
• 基盤規模：モデル300万+ ・ データセット50万 ・ アプリ100万 ・ 開発者1,800万 ・ 法人20万
• 目標：数年以内にAI開発者1億人
• 本人の懸念：少数の大企業へのAI支配の集中

この数字が測っていないこと

• 「使っている」の定義が非公開 — 口座の保有、モデルを一度取得しただけの状態、本番配備が区別されていません
• 自社の公式統計と食い違う：同社の報告書（2026年春）はフォーチュン500の30%以上が認証済みアカウントを持つと記しています — 同じ母集団に二つの数字
• 作業量の割合ではない：「何社が使うか」であって「実際の推論の何%か」ではありません
• 利害関係：基盤事業者の自己申告であり、第三者の検証がありません

🔗 関連リンク： TechCrunch 原記事（2026-07-10） | State of Open Source on Hugging Face: Spring 2026 | Hugging Face

展望：発言そのものは事実と見てよいでしょう。ただし「フォーチュン500の半数がオープンソースへ移行した」と読み替えると誇張になります。正確に言えば「フォーチュン500の半数がオープンソースAIに触れた」に近いのです。この区別が効いてくる理由は、次の項目で明らかになります。

📊 信頼性評価：7.5/10
強み：主要技術メディアによる一次取材であり、発言者・日付・媒体が特定できます。基盤規模の数値は複数のメディアで一致しています。
改善点：「使っている」の測定定義が公開されておらず、第三者による検証もありません。同じ会社の公式報告書が示す「30%以上が認証済みアカウント」とは層が異なる数値であり、併記が必要です。

2. 正反対を指すデータ — 導入率は上がったのに作業量の割合は下がった

現状：ベンチャーキャピタル Menlo Ventures の企業調査によると、企業の大規模言語モデル利用に占めるオープンソースの割合は、2024年の19%から2025年には11%へと下がりました。同じ調査で企業の大規模言語モデル支出は2024年11月の35億ドルから2025年半ばには84億ドルへと半年で倍以上に増え、その88%を Anthropic（40%）・OpenAI（27%）・Google（21%）の3社が占めています。残る12%に Llama・Cohere・Mistral とその他すべてが入ります。一方で Linux Foundation と Meta が共同で出した調査では、AIツールを使う組織の89%が技術基盤のどこかでオープンソースAIを使っていると報告されています。

同じ市場を測った四つの数字

• 50% — フォーチュン500のうち Hugging Face でオープン／自社モデルを配備（HF 最高経営責任者）
• 30%以上 — フォーチュン500のうち Hugging Face の認証済みアカウント保有（HF 公式報告書）
• 89% — AIツールを使う組織のうち基盤の一部にオープンソースAIを使用（Linux Foundation）
• 11% — 企業の大規模言語モデル利用量に占めるオープンソースの割合（Menlo Ventures、2025年）
→ 矛盾ではなく、測っている層が違います。

性能は追いついたのに割合は落ちた

• 差の縮小：最良のオープンモデルと最良の非公開モデルの差は、2023年の20〜30ポイントから大半の評価で5〜10ポイントまで縮まりました
• コーディングは事実上互角で、最も難しい複合的な推論と安全性の領域だけが遅れています
• Llama の停滞が直撃：企業で最も広く使われていたオープンな重みのモデルが伸び悩んだことが、オープンソース全体の割合低下の主因と指摘されています
• 逆説：技術は追いついたのに企業での採用は減りました

🔗 関連リンク： Menlo Ventures — State of Generative AI in the Enterprise | Linux Foundation — World of Open Source Survey | Open-Weight Models Caught Up. Adoption Fell to 11%

展望：二つのデータは衝突していません。オープンなモデルは「広く、浅く」、非公開のAPIは「狭く、深く」使われています。試作、社内ツール、埋め込み、分類といった単価の低い処理ではオープンモデルが広がった一方、費用が集中する高難度の本番推論は依然として最先端3社が押さえています。したがって移行の進み具合を見るには、導入率ではなく支出やトークンの割合を見る必要があります。

📊 信頼性評価：8.0/10
強み：Menlo Ventures の数値は年次で追跡された定量データであり、3社の内訳（40／27／21）まで公開されています。Linux Foundation の調査も機関の出所が確認できます。
改善点：Menlo の数値は2025年時点のもので、2026年の更新版が必要です。標本の構成と「利用量」の定義（支出基準か呼び出し回数基準か）が要約からは判然としません。「89%」も Meta が共著である報告書だという点を踏まえる必要があります。

3. 移れない理由 — 性能ではなく、利用許諾・損益分岐・出所

現状：性能差が5〜10ポイントまで縮まった後も企業の移行が進まない理由は、モデルの外側にある三つの制約に移りました。①利用許諾 — 用途の制限、利用者数の上限、競合による使用の禁止といった条項が付いた「オープン」なモデルが少なくありません。②自社運用の採算 — OECD の損益分岐の試算では、月10億トークンの規模では回収に30か月かかる一方、月100億トークンなら2か月に縮みます。③出所の検証 — 重みの来歴を証明し、改変されていないことを確かめる手立てが乏しい状況です。他方 McKinsey の調査では企業の意思決定層の40%が制御を理由に自社運用できるモデルを選好しており、Forrester は2026年4月にAIモデル開放度の枠組み（AI Model Openness Framework）を公表して「オープン」の等級分けを始めました。

三つの実質的な壁

• 利用許諾：用途の制限・利用者数の上限・競合による使用の禁止 — 「オープンな重み」が「自由に使える」を意味しません
• 損益分岐：月10億トークン → 回収30か月／月100億トークン → 2か月（OECD の試算）
• 出所の検証：重みの来歴の証明と改変の有無を確かめる手立てが不足
• 規制の負担：オープンな重みを使っても、高リスク用途であれば配備する側が順守の責任を負います

それでも移行を押す力

• 制御の選好：意思決定層の40%が自社運用できるモデルを選好（McKinsey）
• 費用の倍率：オープンモデルには最上位の非公開モデルと比べ10〜1,000倍の費用削減が成り立つ領域があります（Hugging Face の集計）
• 監査への対応：自社運用の構成はデータ・記録・モデルの来歴を直接管理でき、監査の摩擦を大きく減らすとの分析
• 主権的な調達：フランスは税務当局の侵害事案を受け、政府システムの脆弱性点検に Mistral など自国事業者を用い OpenAI を除外する方針です

🔗 関連リンク： Forrester | McKinsey & Company | Mistral AI | MLflow — Role of Open Source in Enterprise AI

展望：移行の分かれ目は性能ではなくトークンの使用量です。OECD の数値をそのまま読めば、月10億トークンに満たない組織が自社運用へ移るのはおおむね損であり、月100億トークンを超えると移らない方が損になります。大半の企業がまだ前者の領域にいるため、「半数が使っている」と「実際の作業量では11%」が同時に成り立つのです。

📊 信頼性評価：7.0/10
強み：三つの壁という整理は Forrester の開放度の枠組み（2026年4月）など業界の議論と符合し、損益分岐の方向性も自社運用の採算に関する常識と一致します。
改善点：OECD の30か月／2か月と McKinsey の40%は二次メディアを経由した引用で、原典を直接は確認できていません。「10〜1,000倍の費用削減」は Hugging Face の自己集計であり、前提条件が明示されていません。

4. オープンな重みの重心が中国へ移った

現状：オープン陣営の内部で主導権が入れ替わりました。Hugging Face の公式集計によれば、2025年に中国が月間の取得回数で米国を追い抜き、直近1年で中国発のモデルが全取得回数の41%を占めました。アリババの Qwen 系列は2025年9月に Meta の Llama を抜いて Hugging Face で最も多く取得されるモデル系列となり、2026年の半年間で30億回以上取得され、同期間の Google（4億1,800万回）と Meta（2億2,700万回）の合計を上回りました。派生モデルは Qwen 系列だけで11万3,000点以上と、Google と Meta の合計を超えます。中立的な振り分け業者 OpenRouter の集計では、2026年5月に中国発のオープンな重みのモデルが消費トークン全体の約61%を占めました。

数字で見る移動

• 取得回数の割合：中国発モデルが41%（直近1年、Hugging Face 集計）
• Qwen：2026年の半年で30億回超 ・ 2026年2月の単月で1億5,360万回（次点8社の合計より多い）・ 3月には世界のオープンソース取得の50%超
• 派生モデル：Qwen 系列が11万3,000点以上（タグを含めると20万点超）
• OpenRouter のトークン：2026年5月に中国発が約61%
• 供給側の拡大：百度は2024年0件 → 2025年100件超 ・ バイトダンスとテンセントは各8〜9倍

欧米陣営の組み替え

• Meta：最先端は非公開へ転換。代わりに2026年8月10日、上位モデル Muse Spark から蒸留した約300億パラメータの Muse Glimmer を Apache 2.0（利用者数の上限なし）で公開 — Llama より寛容な条件です
• OpenAI：gpt-oss の重みは2025年8月以降更新されていません。2026年6月時点で後継はなく、ただし gpt-oss-120b が2026年3月に MLPerf Inference v6.0 の公式ベンチマークに採用されました
• 型：最先端は閉じ、蒸留した小型だけを開く — 米国の主要研究所に共通の戦略として定着しつつあります
• 残る選択肢：Gemma ・ Mistral ・ Phi ・ Nemotron ・ OLMo ・ Command A+

🔗 関連リンク： Qwen（アリババ） | DeepSeek | OpenRouter | Meta AI | Hugging Face — State of Open Source Spring 2026

展望：2026年の時点で「オープンソースAIへ移る」という判断は、実質的に「中国発のオープンな重みを使う」という判断とかなりの部分で重なります。これが調達審査に新しい論点をつくります — 性能や価格ではなく、原産地の方針と重みの来歴です。公共・金融・防衛のように出所の制約がある組織は、性能で勝るオープンモデルを前にしながら、欧米のオープンモデルか非公開APIへ戻る判断をすることになります。

📊 信頼性評価：8.0/10
強み：取得回数の割合、国別の逆転、派生モデル数はHugging Face の公式報告書という基盤側の一次データであり、OpenRouter のトークン比率という独立した集計で裏取りができています。
改善点：取得回数は利用量ではありません — 評価や研究目的の取得が大きく混ざります。Qwen の「30億回」と「50%超」は二次集計メディア経由であり、OpenRouter の61%も開発者に偏った特定の経路での値です。

5. 構造の変化 — NVIDIA が Hugging Face を買収した

現状：2026年9月2日、NVIDIA は Hugging Face の買収について確定契約を結び、9月3日に公表しました。買収額は報道ベースでおよそ129億ドルです。ドゥラング氏は「条件が一斉に噛み合った（planets aligned）」と述べ、利用者1億人という目標を掲げたうえで「NVIDIA のような強力な後ろ盾があれば、これからの10年を考えられる」と語りました。問題は中立性です。Hugging Face はNVIDIA の競合となる半導体企業も含め、業界全体が使うモデルの集積所だからです。NVIDIA は「Hugging Face はAI生態系全体に開かれた場であり続ける」とし、「Hugging Face 上で開発・配備するのに NVIDIA の計算資源が必須になることはない」と明言しました。

取引の事実関係

• 確定契約：2026-09-02（米証券取引委員会へ提出）・ 公表：2026-09-03
• 金額：報道ベースで約129億ドル（出所により119億〜130億ドルの幅）
• NVIDIA の約束：開かれた場の維持 ・ モデル／枠組み／クラウド／計算資源の選択の自由 ・ NVIDIA の計算資源を必須としない
• 目標：利用者1億人
• 競争法：短期的には資料提出の求めや予備的審査にとどまるとの見方が有力

規制の層 — EU AI法のオープンソース免除

• 部分的な免除：第53条2項は、オープンソースの汎用AI提供者に技術文書や下流への情報提供の義務の一部を免除します — ただし四つの条件をすべて満たす場合に限ります
• 免除の消滅：学習に用いた計算量が10の25乗 FLOPs を超え「システミックリスク」に該当すると、免除はなくなります
• 配備側の責任は残る：オープンな重みを使っても、高リスク用途であれば配備する側が順守義務を負います
• 示唆：「オープンソースだから規制から自由」という前提は、企業の利用者には成り立ちません

🔗 関連リンク： NVIDIA | CNN — NVIDIA による Hugging Face 買収 | InfoWorld — モデル選択への影響 | EU AI Act
最大の皮肉はここにあります。ドゥラング氏が7月の取材で語った懸念は「少数の大企業がAIを握ってしまうこと」でした。その2か月後、中立性の拠り所だったその場が、AI向け半導体で最も支配的な企業の傘下に入りました。

本レポートの解釈：裏切りというより、中立的な基盤の資金構造がもともと脆いという事実が表に出たと読むのが正確です。モデルの集積所は膨大な保管と通信の費用を負いながら、直接の収益化が難しい事業です。実務で重要なのは宣言ではなく確かめられる指標です — 競合の半導体（AMD、TPU、自社設計チップ）向けの最適化処理と文書が買収後も同じ速さで更新されるか、NVIDIA 以外の実行基盤での推論対応が維持されるかを、6〜12か月にわたって追う必要があります。

展望：この買収により「オープンソースAI」の定義がもう一段複雑になりました。モデルの重みは開かれていても、その重みを探して配る流通の層は、いまや一企業の所有物です。調達の観点では、Hugging Face への一本足を避け、複製先や自社の登録簿、複数の振り分け業者を併用する構成が増えると見ています。根拠は次の2点です。①2026年に入ってモデル集積所をめぐる安全上の事案がすでに注目されたこと、②単一の流通点への依存は、オープンな重みを選んだそもそもの理由（囲い込みの回避）と正面から矛盾することです。

📊 信頼性評価：8.5/10
強み：買収の事実は米証券取引委員会への提出書類と CNN・Fortune・TechCrunch など複数の主要メディアで確認でき、NVIDIA の中立性に関する文言と最高経営責任者の発言は直接引用できます。EU AI法の条項（第53条2項・10の25乗 FLOPs）は法令に基づきます。
改善点：買収額が出所により119億〜130億ドルと食い違います — 提出書類の原文確認が必要です。競争法の見通しは分析者の推測であり、中立性が保たれるかを判断できるデータはまだ存在しません。

競争環境と市場ポジショニング

企業向けAIモデル市場の4層構造

「オープンか非公開か」という二分法では、いまの市場を説明できません。実際の競争は重みの公開の有無 × 原産地 × 流通経路の組み合わせで起きており、次の4層に分けると各陣営が何を売っているのかが見えてきます。とりわけ第4層（流通）はこれまで中立地帯と見なされてきましたが、NVIDIA による Hugging Face 買収で競争上の変数へと浮上しました。

層 主なプレーヤー 提供の仕方 市場での位置 主な制約
1. 最先端の非公開API Anthropic ・ OpenAI ・ Google 最高性能のモデルをAPIでのみ提供 企業の大規模言語モデル支出の88%（40% / 27% / 21%） トークン費用 ・ データの外部送出 ・ 囲い込み
その他の商用API（Cohere など） 特化型API ・ 企業向けの作り込み 残り12%を Llama・Mistral と分け合う 規模の経済で不利
2. 中国発のオープンな重み Qwen（アリババ）・ DeepSeek ・ Kimi ・ GLM 重みを公開し、寛容な利用条件を付す 取得回数とトークンでは事実上の首位 — 取得41%、OpenRouter のトークン約61% 原産地の方針 ・ 調達審査 ・ データ統治
3. 欧米のオープンな重み Meta Muse Glimmer（Apache 2.0）・ OpenAI gpt-oss ・ Google Gemma 最先端は閉じ、蒸留した小型のみ公開 性能の最前線からは後退し、規制に馴染む位置へ移動 更新の停滞 ・ 最先端級の不在
Mistral ・ Nemotron ・ Phi ・ OLMo ・ Command A+ 完全公開型・研究型・欧州の主権型 主権的なAI調達の標準的な選択肢 生態系の規模で不利
4. 流通・配備の層 Hugging Face（→NVIDIA）・ OpenRouter ・ Bedrock / Vertex / Azure ・ vLLM ・ Ollama モデルの探索・保管・振り分け・提供 全層をつなぐ関門 — 中立性が論点化 一本足の危うさ ・ 所有構造の変化

市場の動き 5点

  • 「導入率」と「割合」が逆に動きました。AIを使う組織の89%が基盤のどこかでオープンソースを使う一方、企業の大規模言語モデル利用に占めるオープンソースの割合は19%（2024年）から11%（2025年）へ下がりました。広がったけれども、浅く使われています。
  • 性能はもはや詰まりではありません。最良のオープンモデルと最良の非公開モデルの差は20〜30ポイントから5〜10ポイントへ縮まり、コーディングは事実上互角です。移行を妨げているのは利用許諾の条項、自社運用の損益分岐、重みの出所の検証です。
  • オープン陣営の主導権が中国へ移りました。Qwen が Llama を抜いて最多取得の系列となり、2026年5月には OpenRouter の消費トークンの約61%が中国発のオープンな重みでした。Meta は最先端を閉じ、蒸留した小型のみを開く方式へ転換しています。
  • 「オープン」の内側でも集中が進んでいます。Hugging Face の自己集計では上位200モデル（全体の0.01%）が全取得回数の49.6%を占め、全モデルの約半数は累計取得が200回未満です。開かれていることは多様であることを意味しません。
  • 流通の層が新しい戦場になりました。NVIDIA による Hugging Face 買収（2026年9月）で、重みは開かれていても、それを探して配る関門は一企業の所有となりました。調達の確認項目に流通経路の分散が加わる局面です。

重要なポイント

  • 「フォーチュン500の半数」は事実ですが移行率ではありません。2026年7月の Hugging Face 最高経営責任者の発言はその場を使っている企業の割合であり、同じ会社の公式報告書はフォーチュン500の30%以上が認証済みアカウント保有と記しています。「使う」の定義が非公開のため、本番配備と一度きりの試用が区別できません。
  • 正反対を指すデータが存在します。Menlo Ventures によれば企業の大規模言語モデル利用に占めるオープンソースの割合は19%（2024年）→ 11%（2025年）へ下がり、84億ドルの支出の88%を Anthropic（40%）・OpenAI（27%）・Google（21%）が占めました。オープンモデルは広く、しかし浅く使われています。
  • 詰まりは性能ではありません。最良のオープンモデルと非公開モデルの差は20〜30ポイントから5〜10ポイントへ縮まり、コーディングは互角です。残る壁は利用許諾の制限、自社運用の損益分岐（月10億トークンなら回収30か月・月100億トークンなら2か月）、重みの出所の検証です。
  • 「オープンソースへ行く」は実質的に「中国発のモデルを使う」と重なります。Qwen が Llama を抜いて最多取得の系列となり、2026年5月には OpenRouter の消費トークンの約61%が中国発でした。Meta は最先端を閉じ、蒸留した小型（Muse Glimmer、Apache 2.0）のみを開く方向へ転換しました。
  • 中立的な流通の層が消えました。2026年9月、NVIDIA が Hugging Face を約129億ドルで買収しました。NVIDIA は「NVIDIA の計算資源を必須にしない」と約束しましたが、その2か月前に同じ最高経営責任者が警告した「少数の大企業へのAIの集中」が自社に当てはまった形です。

状況別の参考

月間トークンが10億未満 → 最先端APIを維持
理由：損益分岐の試算では回収に30か月かかります。この領域で自社運用へ移る判断は、費用ではなく制御や規制を理由にしてのみ正当化されます。
月間トークンが100億以上 → オープンな重みの自社運用を検討
理由：同じ試算で回収期間が2か月に縮みます。「移行」の実質的な分かれ目は性能ではなくこの点です。
原産地の制約がある調達（公共・金融・防衛）→ 欧米のオープンな重み、または非公開API
理由：性能で勝るオープンモデルの多くが中国発です。Gemma・Mistral・Nemotron・OLMo 系列が代替となり、EU の高リスク用途ではオープンな重みを使っても配備側が順守責任を負います。
囲い込みの回避が移行の理由だった組織 → 流通経路も併せて分散
理由：重みを開いても集積所一か所に依存すれば、囲い込みは流通の層へ移るだけです。複製先・自社の登録簿・複数の振り分け業者による構成が必要になります。

総合評価：中立（オープンモデルの性能と裾野は実際に大きく伸びており、これは確かな事実です。しかし「フォーチュン500の半数が移行中」という語り口は測定の層を混ぜた結果であり、費用が動く作業量ではオープンソースの割合はむしろ減りました。2026年の本当の変化は移行の加速ではなく、オープン陣営の重心が中国へ、流通の層の所有権が NVIDIA へ移ったことです。）

主要用語の説明

オープンな重み（オープンウェイト） - 学習済みの数値（重み）を取得して自分で動かせるように公開したもの。学習データや訓練の手順まで公開する完全なオープンソースとは異なり、「オープン」と名が付いていても用途の制限が課されている場合が多くあります。
自社運用（セルフホスティング） - APIを借りて使う代わりに、自社の設備やクラウドにモデルを載せて動かす方式。固定費（演算装置と運用）を負う代わりにトークンごとの課金がなくなるため、使用量が多いほど有利になります。
損益分岐 - 自社運用の固定費が、API のトークン費用の削減分で回収できるようになる時点。月10億トークンで約30か月、月100億トークンで約2か月と試算されています（OECD）。
モデルの来歴（プロヴィナンス） - この重みを誰が何から作ったのか、途中で改変されていないかを証明すること。オープンな重みの導入を阻む現実的な障害のひとつです。
派生モデル - 公開されたモデルに追加学習や圧縮を施してつくられた変形版。その系列の生態系の大きさを示す指標であり、Qwen 系列は11万点を超えます。
蒸留（じょうりゅう） - 大きく強いモデルの能力を小さなモデルへ移し替える手法。Meta の Muse Glimmer（約300億パラメータ）は上位の Muse Spark から蒸留したもので、「最先端は閉じ、蒸留版だけを開く」戦略の一例です。
振り分け業者（OpenRouter など） - 複数社のモデルをひとつの窓口にまとめ、要求を適したモデルへ回す仲介の仕組み。特定の事業者に偏らないため、実際の利用割合を観察するのに適した数値の出所です。
システミックリスク ・ 10の25乗 FLOPs - EU AI法が定めた境目。学習に用いた計算量がこの値を超えると波及力の大きなモデルとみなされ、オープンソースの免除がなくなって全面的な義務が課されます。
配備者（デプロイヤー） - モデルをつくって世に出す提供者とは別に、そのモデルを実際の業務に持ち込んで使う組織。EU AI法では、高リスク用途であればオープンな重みを使っていても配備者が順守の責任を負います。
