Key Terminology

Large Language Model (LLM) — An AI model trained on vast text datasets that can generate and understand human-like natural language. Prominent examples include ChatGPT, Claude, and Takane
AI Agent — An AI program that autonomously makes decisions and takes actions toward a specific objective. Systems where multiple agents collaborate are called "multi-agent systems"
SWE-bench — A benchmark that measures AI performance on software engineering tasks by evaluating the ability to resolve real GitHub issues. Claude Opus 4.5 holds the top score at 80.9%
AI-Ready Engineering — A preparatory process for ensuring successful AI-driven automation. Encompasses organizing existing system assets, standardizing development rules, and codifying tacit knowledge. Pioneered by Fujitsu
JGLUE — A Japanese natural language understanding benchmark. Evaluates LLM Japanese processing capabilities through tasks including natural language inference (JNLI) and machine reading comprehension (JSQuAD)
Hallucination — The phenomenon where AI generates plausible-sounding but factually incorrect information. Fujitsu has built a detection and correction system through its Guardian Layer
Quantization — A technique that intentionally reduces the computational precision of AI models to decrease memory usage and improve processing speed. Takane's 1-bit quantization achieves a 94% memory reduction
Fujitsu Kozuchi — Fujitsu's AI services platform encompassing seven domains: generative AI, AutoML, predictive analytics, image recognition, text analytics, AI trustworthiness, and explainable AI
