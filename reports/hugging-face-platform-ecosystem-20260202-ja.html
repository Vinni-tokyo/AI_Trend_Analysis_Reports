Hugging Face：オープンソースAIプラットフォームの覇者

モデルハブ、Transformers v5、LeRobot、smolagentsの最新動向分析
レポート作成日：2026年2月2日 | 標準版レポート

主要トレンド Top 5

1. Transformers v5：PyTorch最優先のモジュラーアーキテクチャ

現状：Hugging Faceは、v4リリースから5年を経てTransformers v5をリリースしました。1日あたり300万回以上のインストール、累計12億回以上のダウンロードを記録し、AIエコシステムの中核ライブラリとしての地位を確立しています。

核心機能

• PyTorch最優先：TensorFlow/Flaxサポートを終了し、PyTorch最適化に集中
• モジュラー設計：AttentionInterfaceなど共通コンポーネントの標準化
• 量子化対応：8-bit、4-bitの低精度フォーマットをネイティブサポート

主要データ

• 対応モデル数：400以上（v4の40から10倍増加）
• Hub上のチェックポイント：75万以上（v4時点の1,000から750倍）
• GitHub Stars：121,000（PyTorch 76,000を大幅に上回る）

関連リンク： Transformers Documentation | v5リリースブログ | GitHub Repository

展望：v5の登場により、モデル開発の標準化と相互運用性が大幅に向上。特に量子化のネイティブサポートにより、エッジデバイスでのAI展開が加速する見込みです。

2. LeRobot：オープンソースロボティクスの民主化

現状：Hugging Faceは2024年にLeRobotライブラリを立ち上げ、2025年にはPollen Roboticsを買収してハードウェア展開を本格化。$100のSO-100アームから$3,000のHopeJRまで、幅広い価格帯でオープンソースロボットを提供しています。

主要製品

• SO-100アーム：約$100の高性能ロボットアーム（The Robot Studio共同開発）
• Reachy Mini：約$250のカメ型追従ロボット
• HopeJR：約$3,000のデュアルアームロボット（遠隔操作対応）

技術的進歩

• LeRobot v0.4.0：Datasets v3.0、PI0.5/GR00T N1.5モデル統合
• NVIDIAコラボ：GR00T N1人型ロボット基盤モデル統合
• VLAモデル：Physical Intelligenceのpi0/pi0.5ポリシー統合

関連リンク： LeRobot Hub | GitHub Repository | Documentation

展望：オープンソースAIロボティクスは、オープンモデル＋オープンデータセット＋3Dプリント可能なハードウェアの組み合わせにより、研究者から趣味の愛好家まで幅広い層に普及が進む見込みです。

3. smolagents：コードで思考するAIエージェントフレームワーク

現状：2025年、AIエージェントの年に合わせてHugging Faceがリリースしたsmolagentsは、わずか数行のコードでAIエージェントを構築できるミニマリストライブラリです。約1,000行のコードに全ロジックを凝縮しています。

核心機能

• Code Agents：JSONではなくコードでアクションを記述（ネスト、ループ、条件分岐対応）
• サンドボックス実行：Modal、Blaxel、E2B、Dockerでの安全な実行
• Hub統合：エージェントとツールをGradio Spacesとして共有可能

モデル柔軟性

• モデル非依存：transformers、ollama、Hub上のプロバイダー全対応
• LiteLLM統合：OpenAI、Anthropicなど主要LLMプロバイダー対応
• 競合ポジション：OpenAI Swarm、Magentic-Oneより軽量・シンプル

関連リンク： smolagents Documentation | GitHub Repository | smolagents.org

展望：コードベースのエージェントは、JSONベースより表現力と柔軟性に優れ、複雑なタスクの自動化に適しています。DeepLearning.AIも専門コースを提供するなど、教育面でのサポートも充実しています。

4. Model Hub：200万モデルを擁するAIの「GitHub」

現状：Hugging Face Hubは、150万以上のモデルと34万以上のデータセットをホスティングし、5万以上の組織に採用されています。テキスト、画像、音声、動画、3Dモデルまで、あらゆるAIモダリティをサポートしています。

プラットフォーム規模

• 登録ユーザー：120万人以上（2023年時点）
• 利用企業：7,774社（2025年確認済み）
• 年間収益：約$130M（2024年、前年比85%増）

エンタープライズ機能

• プライベートHub：組織専用のモデル・データセット管理
• SOC 2準拠：エンタープライズセキュリティ標準
• クラウド統合：AWS、Azure、Google Cloudとのシームレス連携

関連リンク： Hugging Face Hub | Enterprise Hub | Pricing

展望：OpenAIが5モデルを提供する一方、Hugging Faceは「数百万」のモデルを提供。ベンダーロックインを回避するニュートラルなエコシステムとして、企業のAI戦略における重要性が高まっています。

5. Inference API：サーバーレスからエンタープライズまで

現状：Hugging Faceは、無料のServerless Inference APIから専用のInference Endpointsまで、幅広い推論サービスを提供。2025年7月からはCPU推論に特化し、GPU推論はInference Providersへ移行しています。

サービス階層

• Serverless API：無料、レート制限あり（数百リクエスト/時間）
• PRO Account：$9/月、より高い優先度と推論クレジット
• Dedicated Endpoints：専用ハードウェア、オートスケーリング対応

料金体系

• Free：$0/月（公開モデル・データセットアクセス）
• Team：$20/ユーザー/月（SSO、監査ログ）
• Enterprise：$50+/ユーザー/月（カスタムSLA、専任サポート）

関連リンク： Serverless Inference API | Pricing & Billing

展望：Replicate等との統合により、Hugging Face Hubからシームレスに推論実行が可能に。マルチプロバイダー戦略により、ユーザーは最適なインフラを選択できるようになっています。

選択ガイド

主要用語の説明

Transformers - Hugging Faceの中核ライブラリ。事前学習済みモデルのロード、ファインチューニング、推論を簡単に行えるPythonライブラリ。
Model Hub - AIモデル、データセット、デモアプリを共有・発見するためのプラットフォーム。GitHubのAIモデル版。
LeRobot - ロボティクス向けのオープンソースライブラリ。実ロボット制御からVLAモデル学習まで、PyTorchベースで提供。
smolagents - コードでアクションを記述するミニマリストAIエージェントライブラリ。JSONベースより表現力が高い。
VLA（Vision-Language-Action）モデル - 視覚、言語、行動を統合するロボット向け基盤モデル。Physical IntelligenceのPI0などが代表例。
