Microsoft Purview와 Agent 서비스 분석
AI 시대의 데이터 거버넌스와 자율 에이전트

데이터 보안, 컴플라이언스, 그리고 엔터프라이즈 AI 에이전트 생태계
레포트 작성일: 2026년 2월 2일 | 표준 보고서 (5-8페이지)

주요 트렌드 Top 5

1. Microsoft Purview Unified Catalog: AI 기반 데이터 거버넌스의 핵심

현황: Microsoft Purview는 AI 시대의 데이터 거버넌스, 보호, 관리를 위한 통합 솔루션입니다. Unified Catalog과 Data Map을 통해 분산된 데이터 소스에서 메타데이터를 통합하고, AI 기반 추천으로 데이터 품질과 큐레이션을 간소화합니다. 2025년 10월부터 신규 테넌트에 새로운 레이블 체계가 자동 적용되며, 가상 네트워크(vNet) 프로비저닝이 일반 제공(GA)되었습니다.

핵심 기능

• Unified Catalog: SaaS 기반 단일 테넌트 모델로 데이터 검색, 품질 관리, 접근 권한 부여
• AI 기반 자연어 검색: 비즈니스 목적에 맞는 데이터 제품을 자연어로 검색 (프리뷰)
• Data Map: 멀티클라우드 소스에서 메타데이터 자동 스캔 및 수집

AI 거버넌스 강화

• Copilot 통합: 거버넌스 작업 자동화 및 실시간 정책 시행
• DSPM for AI: AI 앱의 민감 정보 위험 탐지 및 권고사항 제공
• 사용량 모니터링: 거버넌스 도메인별 DGPU 소비량 추적 (프리뷰)

🔗 관련 링크: Microsoft Purview | Unified Catalog 문서 | 최신 업데이트

전망: Microsoft Fabric과의 긴밀한 통합으로 Power BI Copilot의 데이터 보안 및 컴플라이언스 제어가 GA되었으며, 2026년에는 AI 워크로드 전반의 통합 거버넌스가 더욱 강화될 전망입니다.

2. Azure AI Foundry Agent Service: 엔터프라이즈급 멀티에이전트 플랫폼

현황: Azure AI Foundry Agent Service는 개발자가 AI 에이전트를 안전하게 설계, 배포, 확장할 수 있는 플랫폼입니다. Microsoft Ignite 2025에서 멀티에이전트 워크플로우, 영구 메모리, 엔터프라이즈 거버넌스를 지원하는 새로운 버전이 공개되었습니다. OpenAI와 Anthropic 모델을 모두 제공하는 유일한 클라우드 플랫폼입니다.

핵심 기능

• 멀티에이전트 오케스트레이션: 순차, 동시, 핸드오프, Magentic 패턴 지원
• Computer Use Tool: UI를 통한 컴퓨터 시스템 자동 조작 (프리뷰)
• Deep Research: 웹 전반에서 정보 계획, 분석, 합성하는 고급 연구 기능

엔터프라이즈 통합

• 1,400+ 액션 커넥터: Azure Logic Apps 기반 광범위한 통합
• M365 원클릭 배포: Copilot과 Teams로 즉시 배포 가능
• 모델 라우터: 비용, 성능, 품질 균형을 위한 동적 모델 선택

🔗 관련 링크: Foundry Agent Service | 문서 | Deep Research

전망: Foundry Control Plane의 퍼블릭 프리뷰로 어디서 만들어진 에이전트든 통합 관리가 가능해졌으며, Claude Sonnet 4.5, Opus 4.1, Haiku 4.5 등 Anthropic 모델이 추가되어 모델 선택의 폭이 넓어졌습니다.

3. Microsoft Agent Framework: 오픈소스 멀티에이전트 SDK

현황: Microsoft Agent Framework는 .NET과 Python을 지원하는 오픈소스 AI 에이전트 개발 도구입니다. Semantic Kernel과 AutoGen의 강점을 통합하여 단일 프레임워크로 제공합니다. 그래프 기반 워크플로우, 체크포인팅, 휴먼인더루프 기능을 포함하며, OpenTelemetry 통합 관측성을 제공합니다.

프레임워크 기능

• 그래프 기반 워크플로우: 스트리밍, 체크포인팅, 타임트래블 지원
• A2A 프로토콜: 에이전트 간 협업을 위한 표준 통신 지원
• MCP 통합: 동적 도구 연결을 위한 Model Context Protocol

개발자 경험

• VS Code AI Toolkit: 멀티에이전트 워크플로우 시각화 및 디버깅
• Python/C# 지원: 일관된 API로 두 언어 모두 완전 지원
• OpenAPI 통합: 모든 API와의 통합 가능

🔗 관련 링크: GitHub 저장소 | 문서 | 블로그

전망: Azure AI Foundry와의 통합으로 관리형 런타임에서 멀티에이전트 워크플로우를 실행할 수 있으며, 엔터프라이즈 거버넌스와 텔레메트리 기능이 강화되고 있습니다.

4. Microsoft 365 Copilot Agents: 협업 중심 AI 팀메이트

현황: Microsoft는 Ignite 2025에서 모든 팀, 프로젝트, 회의에 AI 팀메이트를 제공하는 협업 중심 에이전트를 발표했습니다. Agent 365는 에이전트의 컨트롤 플레인으로, Entra Agent ID를 통해 이메일, Teams, SharePoint 전반에서 에이전트 ID와 감사를 관리합니다.

주요 에이전트

• Facilitator Agent: 회의 안건 관리, 노트 작성, 액션 관리 (GA)
• SharePoint Agent: 메타데이터 태깅, 파일 분류, 콘텐츠 분석 자동화
• Sales Agent: 리드 검색, 자격 확인, 개인화된 아웃리치 자동 수행

Work IQ 레이어

• 장기 기억: 사용자 역할, 회사 구조, 프로젝트 이력 지속 인식
• Agent Mode: 채팅과 Office 앱에서 에이전트 모드 지원 (2026 초 프리뷰)
• 컨텍스트 인식: 이메일, 캘린더, 커뮤니케이션 패턴 전반 이해

🔗 관련 링크: Copilot Studio | Ignite 2025 발표

전망: 2026년 7월부터 M365 구독에 AI 및 보안 기능이 기본 포함되며 가격이 인상됩니다. GPT-5 모델(GPT-5 Auto, Chat, Reasoning)이 Copilot Studio에서 퍼블릭 프리뷰로 제공됩니다.

5. Purview AI 컴플라이언스: 생성형 AI 시대의 데이터 보호

현황: Microsoft Purview는 생성형 AI 앱의 데이터 보안과 컴플라이언스를 위한 통합 보호 기능을 제공합니다. Information Protection, DLP, Insider Risk Management, DSPM for AI가 함께 작동하여 민감 데이터 분류, 유출 방지, 내부자 위협 탐지, AI 관련 위험을 발견합니다.

AI 보안 기능

• DSPM for AI: AI 앱의 데이터 보안 태세 관리
• 머신러닝 탐지: 비정상 행동 패턴 감지 및 데이터 유출 방지
• 실시간 대시보드: 컴플라이언스 모니터링 및 자동 감사 보고서

규제 대응

• 글로벌 규정: GDPR, HIPAA, CCPA, ISO 27001 대응
• M365 Copilot 뷰: Copilot 전용 데이터 보안 및 컴플라이언스 관리
• eDiscovery/보존: AI 상호작용의 감사 및 보존 정책

🔗 관련 링크: AI 시대 Purview 혁신 | 데이터 거버넌스

전망: AI 사용이 증가함에 따라 조직은 AI 관련 위험을 완화하고 적절한 보호 및 거버넌스 제어를 구현해야 합니다. Purview는 AI 워크로드 전반의 통합 보안 솔루션으로 자리매김하고 있습니다.

활용 아이디어

시장에서 관찰되는 주요 활용 접근방식을 소개합니다.

1. AI 거버넌스 파일럿 - Purview DSPM for AI를 활용하여 기존 Copilot 사용 패턴 분석 및 민감 데이터 위험 식별 후 단계적 정책 수립

2. 멀티에이전트 업무 자동화 - Foundry Agent Service로 반복적인 비즈니스 프로세스(예: 경비 처리, 문서 라우팅)에 멀티에이전트 워크플로우 구축

3. SharePoint 지식 관리 - SharePoint Agent로 문서 메타데이터 자동 태깅 및 콘텐츠 신선도 분석을 통한 지식 베이스 현대화

에그제큐티브 서머리

핵심 발견

  • 통합 거버넌스: Purview는 데이터 거버넌스 시장 1위(17.1%)로, AI 시대 데이터 보호와 거버넌스를 통합 제공
  • 에이전트 생태계: Microsoft는 Foundry Agent Service(엔터프라이즈), Copilot Studio(로우코드), Agent Framework(개발자)로 전 계층 커버
  • 2026년 전환: M365 구독에 AI/보안 기능 기본 포함, GPT-5 모델 도입, 가격 인상 예정(2026.7)
  • 멀티모델 전략: Azure는 OpenAI와 Anthropic 모델을 모두 제공하는 유일한 클라우드
  • 오픈 표준: A2A, MCP, OpenAPI 지원으로 멀티벤더 환경에서의 상호운용성 확보

선택 가이드

Microsoft 생태계 기업 → Purview + Copilot Studio
이유: Azure/M365/Power BI 네이티브 통합, 낮은 도입 비용, 빠른 가치 실현

멀티클라우드/복잡 환경 → Collibra 또는 Informatica
이유: 플랫폼 독립적인 고급 거버넌스 기능 필요 시

개발자 주도 AI 에이전트 → Agent Framework + Foundry
이유: 오픈소스 유연성과 엔터프라이즈 관리 기능의 조합

종합 전망: 긍정적 (Microsoft는 AI 시대의 데이터 거버넌스와 에이전트 서비스에서 포괄적인 솔루션 포트폴리오를 구축하고 있으며, 특히 기존 Microsoft 생태계 기업에게 매력적인 선택지)

주요 용어 설명

Unified Catalog - Microsoft Purview의 핵심 구성요소로, 조직 전체의 데이터를 검색하고 큐레이션하는 SaaS 기반 데이터 카탈로그
DSPM for AI (Data Security Posture Management for AI) - AI 애플리케이션의 데이터 보안 태세를 관리하고 위험을 식별하는 Purview 기능
Foundry Agent Service - Azure AI Foundry의 관리형 에이전트 런타임으로, 멀티에이전트 오케스트레이션과 엔터프라이즈 거버넌스 제공
Agent 365 - Microsoft 365 환경에서 에이전트를 관리하고 보안하는 컨트롤 플레인
A2A (Agent-to-Agent Protocol) - 서로 다른 벤더의 AI 에이전트 간 협업을 가능하게 하는 표준 프로토콜
MCP (Model Context Protocol) - AI 모델을 데이터 소스에 연결하기 위한 표준 프로토콜
Work IQ - Copilot의 장기 기억 레이어로, 사용자 역할과 프로젝트 이력을 M365 전반에서 지속적으로 인식
