Key Terminology

Personal AI Agent - AI software that autonomously performs real-world tasks on behalf of the user, such as web browsing, email management, calendar scheduling, and information retrieval. OpenClaw and Manus are leading examples.
Self-Hosted - A deployment model where the AI agent runs on the user's own server or PC, providing complete data control. Security configuration is the user's responsibility. OpenClaw and NanoClaw follow this model.
Container Isolation - A security technique that executes AI agents within Linux containers (e.g., Docker), physically preventing access to the host operating system. This is the core security mechanism of NanoClaw.
Prompt Injection - An attack vector where malicious inputs manipulate an AI agent's behavior, potentially hijacking its tools and data stores. Personal AI agents are particularly vulnerable to injection via email content and web pages.
Multi-Agent Orchestration - An architectural pattern in which multiple AI agents coordinate to execute complex tasks. Manus's Planner Agent, which decomposes and distributes sub-tasks, is a canonical example.
Persistent Memory - The capability of an AI agent to retain conversational history and operational context over extended periods, enabling adaptation to user behavior patterns. This is one of OpenClaw's primary differentiators.
